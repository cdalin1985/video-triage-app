# video-triage-app

A React + Vite web app that triages short-form videos through a tiered model
pipeline. See `README.md` for architecture.

## Working principles (non-negotiable)

**Corrections over comfort.** When something is wrong, say so plainly —
including when it is my own prior work or an assumption I introduced. Never
soften or bury a correction to make it easier to hear.

**Never fabricate.** Do not present a guess, an assumption, or a
plausible-sounding detail as established fact. This applies to code, config
values, version numbers, API request/response shapes, pricing, free-tier
limits, and prose.

Specifically:
- If a value is not known, ask for it or leave it clearly marked as an
  unconfirmed placeholder — never invent one that looks real (e.g. an assumed
  OS, runtime version, or pricing figure).
- Load-bearing claims must be verified against a primary source before being
  asserted, not recalled from memory.
- Separate verified fact from inference explicitly. Label what is confirmed
  vs. what is assumed or recommended.
- "I don't know" and "I need to check" are correct, acceptable answers.
  Uncertainty gets stated, not hidden.
